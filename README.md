Food Ordering App – Frontend

A modern, responsive food ordering web application built using React and Redux Toolkit.
This frontend communicates with a secure .NET backend API and provides a smooth user experience for browsing, ordering, and managing accounts.

🚀 FEATURES:

🔐 JWT-based Authentication (Login/Register)
🛒 Add to Cart & Order Management
⚡ Fast and scalable state management with Redux Toolkit
📱 Fully responsive UI
🔄 API integration with .NET backend
❌ Error handling & loading states


🛠️ TECH STACK:

React JS
Redux Toolkit (RTK)
RTK Query (API calls)
Bootstrap (customize based on your setup)


⚙️ INSTALLATION AND SETUP:

# Clone the repository
git clone https://github.com/AwaisVU/GrillFusion_React.git

# Navigate into the project
cd grillfusion_react

# Install dependencies
npm install

# Start the development server
npm run dev

🔐 Environment Variables

Create a .env file in the root:

VITE_API_BASE_URL=http://localhost:5130/

🔗 API Integration

This frontend connects to the backend API:
👉 https://github.com/AwaisVu/FusionGrill_API
